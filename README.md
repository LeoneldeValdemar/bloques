# Bloques

Juego de bloques que caen, en un solo archivo HTML. No necesita instalar nada.

**Jugar en línea:** https://alephramos.github.io/bloques/

## Cómo correrlo

- Abre `index.html` en cualquier navegador (doble clic), o
- entra al enlace de arriba.

## Controles

| Tecla | Acción |
|---|---|
| ← → | Mover |
| ↑ / X | Girar |
| ↓ | Bajar más rápido |
| Espacio | Soltar de golpe |
| P | Pausa |
| Enter | Empezar |

En el celular aparecen botones táctiles debajo del tablero.

## Reglas

- Completa una línea horizontal para borrarla.
- Cada 5 líneas subes de nivel y las piezas caen más rápido.
- El juego termina cuando las piezas llegan arriba.
